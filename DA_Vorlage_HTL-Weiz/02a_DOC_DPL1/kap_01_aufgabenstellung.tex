\section{Individuelle Aufgabenstellung}

Um den Zielen der Diplomarbeit gerecht zu werden, wurden folgende Aufgaben definiert, die im Rahmen der Arbeit bearbeitet werden sollen:
\begin{itemize}
    \item Entwicklung einer Webbasierenden Applikation zur Erfassung der Bewerbe
    \item Entwicklung einer Schnittstelle zwischen Lichtschranke und Zeitnehmerapplikation
    \item Containerisierung der Zeitnehmerapplikation mittels Docker
    \item Orchistrierung des in Microservice Architektur aufgebauten Systems mittels Kubernetes
    \item Implementierung von automatisierten Tests und Images mittels GitHub Actions
\end{itemize}
